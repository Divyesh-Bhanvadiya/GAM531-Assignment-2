# Assignment 2
## GAM531 - Game Engine Foundations 

I have used the **OpenTK** library since the goal of the assignment 1 was to render a 2D rectangle in an OpenGL Window, which can only be done using this library. The SharpDX library is used to work with DirectX.

## Operations implemented

### 1. Vector Operations
- Created two vectors `a(1,2,3)` and `b(4,5,6)`
- Implemented Addition, Subtraction, Dot Product and Cross Product
- See console output after running the project to see results

### 2. Matrix Operations
- Implemented `Rotation` and `Scaling` to a triangle
- See Game Window for results

## How to run the project

1. Clone the project
```bash
git clone https://github.com/Divyesh-Bhanvadiya/GAM531-Assignment-2.git
```
2. Open in the IDE of your choice and install `OpenTK (4.9.4)` as a dependency.
3. Build and run the project.
4. Check console for vector results and game window for matrix results.
